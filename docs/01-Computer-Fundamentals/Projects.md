# 01 计算机基础 · 项目

> 成熟度：已完成

## 项目名称

AI 产品运行环境体检器。

## 目标

在启动 AI 应用前检查 Python 版本、操作系统、默认编码、当前工作目录、磁盘空间和 localhost 解析，输出人类可读报告与 JSON 报告。项目用于训练系统观察、错误隔离和隐私边界，不执行修复命令。

## 功能需求

- Python 版本低于 3.13 时返回失败状态。
- 每个检查返回名称、状态、摘要和安全详情。
- 单项异常被捕获，其他检查继续执行。
- 支持文本与 JSON 两种输出。
- 只读取允许列表字段，不打印完整环境变量、用户名或密钥。
- 提供确定性单元测试；环境相关字段采用范围或类型断言。

## 架构

~~~mermaid

    FS --> REPORT
~~~

## 里程碑

第一步定义结果数据结构和失败语义；第二步逐个实现无副作用检查；第三步建立调度与报告；第四步编写测试；第五步在两个不同环境运行并比较。

## 交付物

源码、pyproject.toml、uv.lock、README、测试、示例文本输出、示例 JSON 输出和一份故障复盘。
