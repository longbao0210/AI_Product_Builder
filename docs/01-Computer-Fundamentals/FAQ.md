# 01 计算机基础 · 常见问题

> 成熟度：已完成

## 是否需要先学习高等数学

不需要。本模块关注计算机系统的可操作模型。二进制只需要基础整数概念；更深入的概率和线性代数会在 AI 基础模块按需引入。

## Windows、macOS 和 Linux 应该选哪个

选择你当前能够稳定使用的平台。课程使用 Python 标准库和跨平台路径。遇到命令差异时记录系统与 Shell，不强求输出字符完全相同，而要确认语义一致。

## 终端会不会很危险

终端只是输入命令的界面，风险来自命令权限与副作用。先理解命令，使用普通权限，在练习目录操作，避免执行来源不明的删除、覆盖或系统配置命令。

## 内存和磁盘有什么区别

内存适合程序运行时快速读写，容量较小且通常断电丢失；磁盘用于长期保存，速度和访问方式不同。性能问题需要先确认数据实际位于哪一层。

## 程序、进程和线程有什么区别

程序是可执行的代码与资源；进程是一次运行实例；线程是进程内部的执行单元。一个程序可以启动多个进程，一个进程也可能包含多个线程。

## DNS 正常是否表示网络一定正常

不是。DNS 只解决名称解析；后续连接仍可能被端口、防火墙、证书、代理、路由或远端服务影响。应按层验证。

## 环境变量可以安全保存密钥吗

环境变量便于注入配置，但并非天然安全。生产环境应使用秘密管理系统，限制读取权限，避免日志打印，并定期轮换。

## 为什么同一代码在别人电脑上可以运行

常见原因包括 Python 版本、依赖锁、当前目录、环境变量、文件权限、字符编码和网络配置不同。记录环境并使用 uv 与锁文件可以减少差异。

## 如何判断已经学会

能够不用资料解释关键边界，运行与修改 Demo，复现一个失败，说明证据如何支持结论，并完成环境体检器。
## 学习节奏建议

如果某章概念陌生，先完成生活案例、流程图和最小代码，再阅读理论；如果代码运行失败，不要跳过，应记录完整错误并按本模块方法排查。每天结束用三分钟回答：今天观察到了哪个系统对象，它的边界是什么，失败时看哪里。每完成三章复做一次早期 Demo，确认不是短期记忆。遇到高权限、删除、网络扫描或真实用户数据时停止实验，改用受控目录、localhost 和示例数据。
