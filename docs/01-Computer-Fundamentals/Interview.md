# 01 计算机基础 · 面试准备

> 成熟度：已完成

## 基础题

**程序与进程有什么区别？** 程序是代码与资源，进程是操作系统管理的一次运行实例。回答应补充资源、隔离和生命周期。

**内存与磁盘如何影响 AI 应用？** 上下文、模型中间状态和缓存可能占用内存；文档、索引和日志通常长期存储。回答应结合容量、速度与故障。

**相对路径为什么会失效？** 它通常相对进程当前目录解析，而当前目录可能随启动方式变化。应说明 pathlib 和明确基准。

**Unicode 与 UTF-8 有什么关系？** Unicode 定义字符与码点，UTF-8 定义码点如何编码为字节。

## 场景题

**本地能访问模型，服务器超时，如何排查？** 先比较环境与配置，再按 DNS、连接、TLS、HTTP 和应用层验证；检查代理、端口、超时和供应商状态；不应立即关闭证书校验。

**上传 PDF 后提示不存在，如何排查？** 保存请求标识，确认上传是否成功、路径基准、文件生命周期、权限、容器挂载和清理任务，并避免把用户文件名直接拼接为系统路径。

**日志出现乱码，如何定位？** 找到字节进入和离开系统的边界，确认原编码、解码位置、终端显示编码和重复转换。

## 实操题

编写 Python 程序输出版本、平台和当前目录；为版本检查写测试；解释哪些输出稳定、哪些依赖环境。评价重点是安全、清晰、可重复和错误处理。

## 回答框架

先定义概念，再说明边界和取舍，随后给工作案例、失败情况与验证方法。不会的细节可以说明如何查证，不要编造命令或协议行为。

## 自测标准

能够在五分钟内画出 AI 请求的系统分层，并用十分钟完成一个只读环境检查脚本，输出中不泄露敏感信息。
## 深挖追问

面试官可能继续追问：为什么相对路径在测试中通过而在服务中失败；为什么增加线程不一定提高性能；为什么 DNS 成功后 HTTPS 仍会失败；为什么设置环境变量后已运行进程看不到变化；为什么 UTF-8 文本仍可能产生解析错误。回答时应区分事实与假设，给出分层验证顺序，并说明安全限制。优秀回答不是堆砌命令，而是能选择最小证据排除错误路径，并把一次排查转化为测试或运行手册。
