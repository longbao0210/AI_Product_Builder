# 01 计算机基础 · 学习资源

> 成熟度：已完成

## 选择原则

本模块优先使用官方文档和开放标准。资源用于查证定义、平台差异与命令行为，不要求从头通读。访问日期统一记录为 2026-07-16；若页面改版，请从同一官方站点检索标题。

## 官方资料

- [Python 3 文档](https://docs.python.org/3/)：解释器、标准库、pathlib、os、socket、sys 与 platform。
- [MDN Web 文档：HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP)：请求、响应、状态码和 Web 基础。
- [Microsoft Learn：Windows 命令](https://learn.microsoft.com/zh-cn/windows-server/administration/windows-commands/windows-commands)：Windows 终端命令参考。
- [GNU Coreutils 手册](https://www.gnu.org/software/coreutils/manual/coreutils.html)：Linux 常用文件和文本命令定义。
- [Unicode 标准](https://www.unicode.org/standard/standard.html)：字符、码点与编码的权威入口。
- [IETF RFC 索引](https://www.rfc-editor.org/)：互联网协议标准与历史。

## 使用方式

遇到参数或平台差异时，先在官方资料确认语义，再做最小实验。复制命令前检查适用系统、权限、路径和副作用。标准文本较难阅读时，可以先读本模块解释，再回到原文核对关键词。

## 资源验收

为每章至少保存一条官方资料、一个查阅问题和一个实验结论。引用外部资料时使用自己的语言概括，短引用注明来源，不复制完整受版权保护内容。

## 失效处理

外链失效时优先从原官方域名检索同名页面；若内容已经废弃，记录替代标准、迁移影响和检查日期。不要用来源不明的转载永久替代权威资料。
