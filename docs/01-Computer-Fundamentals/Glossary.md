# 01 计算机基础 · 术语表

> 成熟度：已完成

## 表示与数据

- **位（bit）**：二进制信息的最小单位，取值为零或一。
- **字节（byte）**：通常由八个位组成，是存储与传输的常见计量单位。
- **字符编码**：字符与字节序列之间的映射规则，UTF-8 是常见编码。
- **序列化**：把内存中的结构转换为可存储或传输格式的过程。
- **JSON**：常用于 Web API 的文本数据交换格式。

## 执行与资源

- **中央处理器（CPU）**：执行指令和控制计算流程的硬件。
- **内存**：程序运行时快速读写数据的空间，断电后通常不保留。
- **进程**：正在运行的程序实例，拥有资源与隔离边界。
- **线程**：进程内部可被调度的执行单元。
- **操作系统**：管理硬件、进程、文件、网络和权限的基础软件。
- **运行时**：为程序提供执行语义、库和资源管理的环境。
- **解释器**：读取并执行相应语言程序的实现。

## 文件与网络

- **路径**：定位文件或目录的名称序列，分为相对路径和绝对路径。
- **文件系统**：组织文件、目录、元数据与权限的规则和实现。
- **IP 地址**：网络层用于定位接口的地址。
- **域名系统（DNS）**：把域名解析为地址等记录的分布式系统。
- **端口**：主机上区分网络服务的数字标识。
- **协议**：通信参与方共同遵守的消息格式与交互规则。
- **环境变量**：由进程环境提供的键值配置；不等于安全秘密存储。

## 使用规则

首次出现术语时应结合输入、输出、边界和失败表现解释。不要把内存与磁盘、进程与程序、域名与 IP、终端与 Shell 混为一谈。
## 易混概念对照

程序是静态代码，进程是运行实例；内存保存运行状态，磁盘用于长期存储；终端是交互界面，Shell 解释命令；域名是便于使用的名称，IP 地址用于网络定位，端口用于区分服务；字符是抽象符号，编码决定字符如何变成字节；环境变量是进程配置来源，不是天然安全的秘密库。学习时用“对象、生命周期、所有者、失败表现”四列对照，比只背一句定义更可靠。
