# 01 计算机基础 · 练习

> 成熟度：已完成

## 基础练习

1. 把十进制 42 转换为二进制，并解释位与字节。
2. 使用 platform、sys 和 pathlib 输出操作系统、Python 版本与当前目录。
3. 创建嵌套路径对象，比较相对路径和绝对路径，不写入系统目录。
4. 将“你好，AI”编码为 UTF-8 字节再解码。
5. 使用 socket 解析 localhost，并说明结果中的平台差异。

验收：每题保存代码、命令、预期、实际输出和一句解释。

## 进阶练习

1. 编写函数检查 Python 是否达到 3.13，不满足时返回清楚错误。
2. 编写只显示指定变量是否存在的配置检查，不打印变量值。
3. 为一个文本文件设计安全写入流程，说明覆盖、异常和恢复。
4. 画出浏览器调用 AI API 的 DNS、连接、请求、模型和响应流程。
5. 分析一个“文件不存在”错误，列出至少三种假设和验证命令。

验收：函数具有测试，图表可渲染，诊断结论由证据支持。

## 挑战练习

在环境体检器中加入超时可控的 DNS 检查、磁盘阈值、JSON 输出和非零退出码。所有读取字段使用允许列表；单个检查失败不能导致其他检查丢失。

## 复盘问题

哪些输出依赖机器？哪些输出适合进入日志？哪些数据可能敏感？如果在容器或云函数运行，假设会发生什么变化？写出下一次改进的可验证目标。
## 评分标准

每项练习按四个维度评分：概念解释是否准确，实验是否可重复，证据是否支持结论，操作是否遵守安全边界。只给出正确输出但无法解释原因，不能视为完成；只写理论而未运行实验，也不能视为完成。建议把每次练习保存为独立目录，包含简短说明、源码、命令和输出。复做时先不看旧答案，再比较两次思路，找出哪些知识已经内化、哪些步骤仍依赖记忆。最终请邀请同伴按说明复现，并记录反馈与改进结果。
