# 01 计算机基础 · 模块导读

> 成熟度：已完成

## 模块定位

计算机基础是整条学习路径的地基。本模块不要求电子工程背景，而是帮助你建立可操作的系统模型：信息如何表示，代码如何运行，文件放在哪里，进程如何获得资源，网络请求如何到达服务，以及开发环境为什么必须可重复。

## 学习目标

完成后，你能使用终端和 Python 3.13 观察运行时、路径、编码、进程、DNS 与磁盘；能区分应用错误、系统错误和网络错误；能按照“记录—假设—验证—结论”排查问题；能完成不收集敏感信息的环境体检器。

## 预计时间

建议投入 12—18 小时。阅读约占三分之一，运行 Demo、制造安全失败和完成综合项目约占三分之二。
