# AI Product Builder 0.1.0 发布说明

> 发布日期：2026-07-16
> 发布阶段：首批基础设施与计算机基础模块
> 内容语言：简体中文

## 版本定位

`0.1.0` 建立 AI Product Builder 的长期维护基线。该版本固定课程、项目和 Demo 的编号体系，完成仓库治理与质量门禁，并将 `01-Computer-Fundamentals` 建设为首个可完整学习、练习和验收的课程模块。

本版本不将“目录已存在”等同于“课程已完成”。模块、项目和 Demo 均通过目录中的成熟度字段公开表达建设状态。

## 已交付范围

- 四十个编号课程模块，且每个模块具备十份固定入口文件。
- 二十五个商业 AI 产品项目的产品目标、用户、功能、架构、里程碑和验收契约。
- 二百个稳定 Demo 编号及其模块归属、技术栈和成熟度清单。
- `01-Computer-Fundamentals` 十章正文、练习、项目、术语表、FAQ、面试题和资源导航。
- 三十、九十、一百八十和三百六十五天逐日学习路径。
- 内容、术语、代码、Mermaid、版本、目录与成熟度统一规范。
- 学习、工程、产品、API、Prompt、MCP Server 和 Agent 模板。
- 本地生成器、知识库校验器、pytest 测试、Ruff 检查和 GitHub Actions 工作流。

## 学习入口

1. 从[项目首页](../../README.md)了解知识树、阶段路线和学习方式。
2. 根据可投入时间选择[学习计划](../../learning-paths/README.md)。
3. 阅读[计算机基础模块](../01-Computer-Fundamentals/README.md)，按 `01` 至 `10` 的编号顺序完成正文。
4. 使用模块练习、项目和检查清单形成可验证成果。
5. 通过[路线图](../../ROADMAP.md)确认进入 Python 阶段所需的前置能力。

## 验证方式

```powershell
uv sync --all-groups
uv run ruff check scripts tests
uv run pytest -v
uv run python scripts/validate.py --root .
git diff --check
```

本版本的精确环境、命令输出摘要和数量审计见[首批验证报告](../../reports/batch-01-validation.md)。

## 兼容性

- Python：`3.13+`
- 包与环境管理：`uv`
- 测试：`pytest 9.x`
- 静态检查：`Ruff 0.14.x`
- 文档图表：GitHub 支持的 Mermaid 语法

具体依赖解析结果由仓库根目录的 `uv.lock` 固定。

## 下一批计划
