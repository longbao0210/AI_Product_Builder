# MCP Server 模板

## 服务范围

说明服务器向智能体暴露的资源、提示词和工具，以及明确不提供的能力。列出目标客户端、传输方式、协议兼容范围和运行环境。

## 工具契约

每个工具定义名称、用途、输入模式、输出模式、错误代码、副作用、幂等性和超时。工具描述应帮助模型正确选择，但不能夸大权限。读取与写入能力分开设计，高风险动作要求明确确认。

## 安全边界

采用最小权限身份，验证所有参数，限制路径、域名和数据范围。秘密通过安全存储注入，不进入日志和工具结果。记录审计事件，并对提示注入、越权访问、数据外泄和资源耗尽设置防护。

## 开发运维

提供安装、配置、启动、协议检查、单元测试和集成测试命令。说明健康检查、指标、日志、限流、版本升级和回滚。用受控测试客户端验证工具发现、调用、取消和错误传播。
