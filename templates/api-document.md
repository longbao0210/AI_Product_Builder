# API 文档模板

## 接口概览

说明接口用途、基础地址、协议版本、认证方式、权限范围、速率限制和幂等要求。标明稳定性级别与兼容策略。

## 请求

为每个端点记录方法、路径、路径参数、查询参数、请求头和请求体。字段表包含名称、类型、是否必需、约束、默认值和中文说明。提供可复制示例，但令牌使用明显的示例值。

## 响应与错误

给出成功状态码、响应模式和完整示例。错误采用统一结构，包含机器可读代码、用户可读消息、追踪标识和可否重试。分别说明参数错误、认证失败、权限不足、配额耗尽、模型超时和内部错误。

## 运行约束

记录分页、流式响应、超时、重试、取消、版本废弃和变更日志。提供 curl、Python 与 TypeScript 调用方式，并说明如何在测试环境验证。不得在客户端暴露服务端供应商密钥。
