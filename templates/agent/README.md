# 智能体模板

## 目标与边界

说明智能体服务的用户、要完成的任务、成功标准和明确禁止的行为。区分模型推理、确定性规则、工具执行和人工决策，避免把所有逻辑都交给模型。

## 状态与流程

定义输入、短期状态、长期记忆、计划、工具结果和最终输出的数据结构。给出从接收目标、澄清、规划、执行、观察、修正到结束的状态机。限制最大步骤、时间、成本和重试次数。

## 工具与安全

每个工具声明权限、参数、超时、副作用和确认要求。不可信内容不能覆盖系统策略，外部结果在进入上下文前验证和裁剪。高风险、不可逆或涉及资金与隐私的动作必须人工确认。

## 评测与运营

建立任务成功率、事实性、工具选择、恢复能力、延迟、成本和安全评测。保存必要的追踪信息，支持重放但减少敏感数据。发布采用灰度与回滚，持续分析失败轨迹并把稳定规则下沉到确定性代码。
