# 项目模板

## 项目概览

说明项目名称、目标用户、核心问题、价值主张和成熟度。用一个具体用户场景描述产品如何从输入得到结果，并指出哪些工作由模型完成、哪些工作由确定性程序完成。

## 范围与架构

列出首个可交付版本包含和不包含的功能。描述客户端、服务端、模型、数据库、外部工具和观测系统的边界。记录主要数据流、错误流、权限边界和成本控制策略。

## 开发与运行

给出运行时下限、依赖安装、环境变量、启动、测试和构建命令。所有命令注明运行目录与预期结果。提供示例数据，但不提交真实用户信息或供应商密钥。

## 验收与运营

定义功能、质量、安全、性能和可用性验收标准。记录核心产品指标、模型质量指标、告警条件、发布步骤、回滚方案和事故复盘入口。项目里程碑从概念验证、最小可行产品、生产加固推进到上线复盘。
