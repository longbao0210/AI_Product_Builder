# 模板中心

## 目标

本目录提供学习、产品、设计、接口、提示词、MCP Server 和智能体开发的统一起点。模板用于减少遗漏和促进审查，不用于制造没有事实依据的长文。复制模板后应删除写作指引，并用项目真实信息替换示例。

## 使用顺序

学习过程从学习笔记模板开始；提出产品想法时先写需求文档，再形成 PRD；技术方向确认后编写设计文档和系统设计；对外提供能力时补充 API 文档。模型能力使用提示词模板记录目标、变量、约束和评测。MCP Server 与智能体模板用于建立安全边界、工具契约和运行手册。

## 质量要求

每份成品必须有明确负责人、状态、版本或日期。决策应记录备选方案及取舍，验收标准应可观察，风险应包含缓解措施。敏感值不得写入文档。模板字段不适用时说明原因，不保留空标题。提交前检查内部链接、术语和成熟度。
