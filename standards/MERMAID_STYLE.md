# Mermaid 图表规范

## 选择图表

流程步骤使用 `flowchart LR` 或 `flowchart TD`；系统组件与边界使用架构流程图；交互顺序使用 `sequenceDiagram`；数据关系使用 `erDiagram`；生命周期使用 `stateDiagram-v2`。同一张图只表达一个核心问题。

## 命名与布局

节点文本使用简体中文并放在双引号中，节点标识使用简短英文或数字。阅读主线优先从左到右，步骤较多或移动端阅读时使用从上到下。节点文字保持简短，详细解释放在图后正文。连线标签使用动作或条件，不使用含糊的“处理”。

## 视觉一致性

默认依赖 GitHub Mermaid 渲染，不使用需要外部主题文件的语法。颜色只用于辅助区分类别，并保证黑白显示仍可理解。架构图明确用户、客户端、服务端、模型、数据和外部工具边界；时序图明确失败分支和超时位置。

## 维护要求

图表紧邻首次解释它的正文。跨章节复用的图保存源文件并在图表索引登记。修改组件名时同步修改正文、图和术语表。提交前检查围栏闭合、语法可渲染以及中文标点不会破坏解析。
