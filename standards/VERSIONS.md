# 版本与兼容性策略

## 原则

课程正文描述稳定概念，易变化的运行时、框架和 SDK 版本集中在本文件维护。示例声明兼容下限，锁文件记录最近验证的精确版本。任何“最新”结论都必须在合并前查阅官方来源，不依赖记忆。

## 更新流程

升级前先阅读发行说明和迁移指南，在独立 Demo 中运行安装、类型检查和测试。存在破坏性变化时记录迁移步骤，并保持旧内容在明确支持期内可运行。外部模型名称、价格、配额、法规和平台限制不纳入永久承诺，相关章节标注查验日期与官方来源。

## 锁定策略

Python 项目提交 `uv.lock`，前端项目提交包管理器锁文件，容器镜像使用可追踪标签或摘要。安全修复可以提高锁定版本，但不能在未验证情况下提高全仓兼容下限。
