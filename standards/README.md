# 全仓规范

## 使用方法

本目录是 AI Product Builder 的规则中心。贡献者在编写正文前先阅读写作、术语、Markdown 与 Mermaid 规范；提交代码前再阅读对应语言规范和版本策略。规则冲突时，以设计规格、目录清单和本目录中更具体的规则为准。

## 规范地图

写作规范负责语言、语气、教学节奏和案例质量；术语规范负责中文译名、英文全称及缩写；Markdown 规范负责标题、列表、链接和代码块；Mermaid 规范负责流程图、架构图和时序图；Python 与 TypeScript 规范负责可运行代码；命名规范负责目录、文件、变量和提交信息；版本策略负责运行时下限、依赖锁定和验证日期。

## 变更流程

规范变更必须说明动机、受影响文件、迁移方法和验证命令。涉及术语或命名的改变要一次性修复全仓引用，不能长期保留两套写法。涉及依赖版本的改变先在独立 Demo 验证，再修改版本矩阵和课程正文。所有规则应能被人工审查，适合自动化的部分应逐步加入校验脚本。
