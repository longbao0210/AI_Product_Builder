# Markdown 风格规范

## 标题与段落

每个文件只能有一个一级标题，且必须准确描述文件主题。二级标题承载主要结构，三级标题只用于二级标题内部的稳定分组。标题层级不能跳跃。标题前后保留空行，段落之间保留一个空行。

## 列表与表格

无序列表使用连字符，有序流程使用数字。列表前保留空行，列表项尽量保持同一语法结构。表格只用于字段映射或多项对比；长解释改用小节，避免在移动设备上出现难以阅读的宽表。

## 链接与代码

内部链接使用相对路径并指向真实文件；外部链接使用描述性文本，不直接裸露地址。代码围栏必须声明语言。命令块给出运行目录、前置条件和预期结果，敏感值使用明显的示例占位值。代码中的省略必须明确说明，不能让读者误以为片段可直接运行。

## 可访问性与检查

图片必须有能够表达信息的替代文本。不要只依赖颜色传达状态。提交前运行结构、链接和 Markdown 校验，并确认“下一章”链接与章节编号一致。
