# Python 代码规范

## 运行时与依赖

所有新示例以 Python 3.13 或更高版本为目标，使用 uv 管理依赖和锁文件。依赖必须写入 `pyproject.toml`，不得把全局环境作为隐含前提。Web API 使用 FastAPI，数据验证使用 Pydantic v2。

## 代码结构

公开函数和方法必须使用类型注解，路径使用 `pathlib.Path`，结构化数据优先使用 Pydantic 模型或数据类。函数只承担一个职责，名称表达业务含义。入口代码放在 `main()` 中，并使用明确退出码。异步只用于真实的并发输入输出，不为形式而异步。

## 配置与错误

密钥和环境差异通过环境变量注入，仓库只提交 `.env.example`。捕获异常时选择具体类型，错误消息包含操作和上下文，但不得泄露凭据。网络请求必须设置超时，并说明重试与幂等策略。

## 质量要求

使用 Ruff 统一检查和格式，使用 pytest 编写行为测试。新功能遵循先失败测试、后最小实现的节奏。示例 README 必须给出 uv 安装、运行、测试命令和预期结果。
