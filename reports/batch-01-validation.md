### 统计口径

- 模块目录：`docs/` 下名称符合两位编号前缀的直接子目录。
- 固定入口文件：四十个模块中 `README.md`、`SUMMARY.md`、`Glossary.md`、`Resources.md`、`FAQ.md`、`Best-Practices.md`、`Common-Mistakes.md`、`Exercises.md`、`Projects.md`、`Interview.md` 的实际存在数量。
- 项目目录：`projects/` 下名称符合两位编号前缀的直接子目录。
- 模块 01 章节：模块目录中名称符合两位编号前缀的 Markdown 文件。
- Markdown 文件：`git ls-files '*.md'` 返回的跟踪文件；该值包含本发布说明和本验证报告。
- Mermaid 图：跟踪 Markdown 中 ` ```mermaid ` 或 `~~~mermaid` 开始围栏的数量。
- 失效链接：由 `scripts/validate.py` 对纳入发布范围的 Markdown 相对链接执行检查。
